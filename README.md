# ASP.NET Core на Amvera

Простой пример деплоя ASP.NET Core в [Amvera](https://amvera.ru).

Это тестовое приложение показывает работу Minimal API, статических файлов и персистентное сохранение JSON в постоянное хранилище Amvera.

## Демо-приложение

Приложение имеет веб-интерфейс, на котором вы сразу можете выполнить доступные тестовые запросы.

- `GET /api/health`
- `GET /api/items`
- `POST /api/items`
- `DELETE /api/items/{id}`

## Как правильно сохранять файлы

Изменяемые файлы необходимо сохранять в `/data`. `ContentRootPath` и `WebRootPath` относятся к приложению и не заменяют постоянное хранилище. Если записывать изменяемые в процессе работы приложения файлы мимо постоянного хранилища `/data`, то при каждом перезапуске файлы будут сброшены до состояния загрузки.


```csharp
var dataDir = Environment.GetEnvironmentVariable("DATA_DIR") ?? "/data";
var dataFile = Path.Combine(dataDir, "items.json");
```

## Статические файлы

ASP.NET Core раздает файлы из `wwwroot` после подключения middleware:

```csharp
app.UseDefaultFiles();
app.UseStaticFiles();
```

Собранный файл запускается из `publish`, а рабочая директория процесса может отличаться от директории бинарного файла. Поэтому приложение задает `ContentRootPath` и `WebRootPath` относительно `AppContext.BaseDirectory`, а файл проекта копирует `wwwroot` в результат сборки. Если так не сделать, ASP.NET Core будет искать статику в `/app/wwwroot` и выведет предупреждение `The WebRootPath was not found`.

`UseDefaultFiles` выбирает `wwwroot/index.html`, а `UseStaticFiles` отправляет его содержимое и остальные файлы. Если оставить только `UseDefaultFiles`, сервер может выбрать файл, но не отдать его содержимое.

Важно: ваше приложение будет запускаться на Linux, а названия файлов и пути в Linux чувствительны к регистру: `styles.css` и `Styles.css` являются разными файлами.

## Порт и адрес

Приложение обязательно должно слушать `0.0.0.0` и порт, указанный в конфигурации amvera.yml (может быть практически любым, но главное должен быть равен тому, что указан в коде). В данном примере используется порт по умолчанию: 8080.

## Локальный запуск

```bash
dotnet run --urls http://0.0.0.0:5000
```

Откройте localhost:5000.

## Деплой в Amvera

Для деплоя конкретно этого приложения вам понадобится:

1. Создать аккаунт в [Amvera](https://cloud.amvera.ru);
2. Создать обычное приложение в любом регионе;
3. Загрузить в него код репозитория;
4. Во вкладке "Конфигурация" нажать кнопку "Собрать".

Когда приложение будет готово к работе и статус сменится на "Запущено", во вкладке "Домены" можно будет создать бесплатное доменное имя от Амвера.
